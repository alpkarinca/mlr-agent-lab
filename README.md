# mlr-agent-lab

## Rules Worth Having

- Read README.md and PLAN.md before starting; keep decisions in the repository.
- Try the available tools before asking me to do a technical step by hand.
- Use an isolated Python environment; record versions and commands.
- Run meaningful checks before claiming completion.
- Do not weaken a test to make it pass; explain the disagreement first.
- Never publish secrets or private data; ask before publishing anything.

## Project Files & Workflow

- `README.md` holds the goal and how to run things.
- `PLAN.md` holds progress and the next step.
- `RUNS.md` records the model (/status), what you asked and how you checked it.
- Start each task with *"Make a folder `<task>/` for this task."*
- When a session fills up, save progress in `PLAN.md`, `/clear`, and start again from those files.
